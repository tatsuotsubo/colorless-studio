Tree音で育つ樹形図

音量で枝が伸び、低音で揺れ、アタックで花が咲いて散る。育ち切ると少し休んで新しい木に。

Constellation星座

アタックごとに星が灯り（横=音の高さ、縦=音の明るさ）、近くの星と線でつながる。

Mycelium菌糸

菌糸が這うように伸び、音量で速く、アタックで枝分かれする。古い糸はゆっくり消える。

Pollen風と花粉

花粉が風に流れる。低音で風の曲がり方、アタックで突風、高音で粒の大きさが変わる。

Ripple水面

アタックで水面に石が落ちて波紋（横=音の高さ）、高音は雨粒、低音でうねりが大きくなる。

Smoke煙

床から煙が立ちのぼる。音量で煙の量、低音で渦、アタックで音の高さの位置にふわっと煙が湧く。

Words言葉と記号

アタックで英単語・数字・記号が浮かぶ（タイプ表示か、文字化けから戻る表示）。高音で小さな記号が増える。

Split文字の分離

1つの単語が横の帯に切られ、アタックで帯がずれて左右に裂ける。音量で文字の間隔が開く。強いアタックで単語が変わる。

Corridor奥へ走る空間

カーブする回廊を奥へ走り抜ける。突き当たりの窓にテーマ動画。音量で速度、アタックで加速して手前のゲートが光る。低音で揺れる。

Glitch部分グリッチ・ズーム

動画がアタックで部分的にずれる・色がずれる・モザイクになる。低音や強いアタックでレンズが出て一部を拡大する。

Motionモーショングラフィックス

四角・立方体・円などが Kick に合わせてグリッド上をリズムよく移動し、増えていく。形・動き方・トリガー・色は上で選択。

Roomランダムな部屋

ランダムな部屋（壁・窓・額・家具）を生成し、アタックごとに家具が1つずつ落ちてくる（無音でも1.2秒ごと）。埋まって約16秒（またはアタック15回）で片付いて次の部屋。窓にテーマ動画、ランプは音量、スピーカーは低音、モニターは中域に反応。

Point cloud
表示枠のクリックか「カメラを開始」で映る。Zoom / X / Y で画角を調整。Effect は重ねがけ可、Sens で音への反応の強さ（0 で反応なし）。Point cloud の「人物（AI）」は初回に MediaPipe を jsDelivr から読み込む（使えない環境では「背景差分」：人が映っていない状態で「背景を記録」）。Glitch モジュールの Source を Camera にしてもグリッチできる。claude.ai 上ではブラウザの制限でカメラが使えないことがあり、その場合は Mac の colorless tool フォルダの「start.command」から開くと使える。

Video動画を表示

テーマ動画・読み込んだ動画・カメラ・DAW を表示するだけのモジュール。Aspect で表示する比率（16:9 / 9:16 / 1:1 / 4:5 / シネスコなど）、Fit で合わせ方。Clip change で拍ごとにテーマ動画を切り替え、Beat zoom で拍に合わせて少し寄る。動画ファイルは表示枠にドロップしても読み込める。
